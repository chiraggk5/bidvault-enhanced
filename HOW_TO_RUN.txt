TECH STACK
----------
  Frontend : React 18 + Vite + Tailwind CSS + Socket.IO Client
  Backend  : Node.js + Express + Socket.IO
  Database : MongoDB (Mongoose ODM)
  Auth     : JWT (JSON Web Tokens) + bcryptjs

================================================================
SECTION 1 — PREREQUISITES
================================================================

Before you begin, make sure you have the following installed:

1. Node.js v18 or higher
   Download: https://nodejs.org/en/download
   Verify:   node --version   (should show v18.x.x or higher)

2. npm (comes with Node.js)
   Verify:   npm --version    (should show 9.x.x or higher)

3. MongoDB — choose ONE of the following options:

   OPTION A — MongoDB Atlas (Cloud, Recommended for beginners)
   -----------------------------------------------------------
   a. Go to https://cloud.mongodb.com and create a free account
   b. Create a new Cluster (free M0 tier is fine)
   c. Go to Database Access → Add New User
      - Username: bidvault
      - Password: (choose a strong password)
      - Role: Read and Write to any database
   d. Go to Network Access → Add IP Address → Allow Access from Anywhere
   e. Go to your Cluster → Connect → Drivers
   f. Copy the connection string — it looks like:
      mongodb+srv://bidvault:<password>@cluster0.xxxxx.mongodb.net/bidvault
   g. Replace <password> with the password you set

   OPTION B — Local MongoDB
   ------------------------
   a. Download from https://www.mongodb.com/try/download/community
   b. Install and start MongoDB service
   c. Your connection string will be: mongodb://localhost:27017/bidvault

SECTION 2 — PROJECT SETUP
================================================================

Step 1 — Extract the project
-----------------------------
Unzip bidvault-enhanced.zip to a folder of your choice.
  Example: C:\Projects\bidvault-enhanced  (Windows)
           ~/Projects/bidvault-enhanced   (Mac/Linux)

Step 2 — Open a terminal / command prompt
------------------------------------------
  Windows: Press Win+R, type "cmd", press Enter
           OR right-click the folder → "Open in Terminal"
  Mac/Linux: Open Terminal, navigate to the project folder

  cd path/to/bidvault-enhanced
  (e.g., cd ~/Projects/bidvault-enhanced)

Step 3 — Create the environment file
--------------------------------------
In the project root folder, create a file named ".env"
(copy from .env.example and fill in your values):

  Windows CMD:
    copy .env.example .env

  Mac/Linux:
    cp .env.example .env

Now open .env in any text editor (Notepad, VS Code, etc.)
and set your values:

  MONGODB_URI=<your MongoDB connection string from Section 1>
  JWT_SECRET=supersecretkey_changethis_inproduction_12345
  PORT=5000
  NODE_ENV=development

  IMPORTANT: JWT_SECRET can be any long random string.
  Example: JWT_SECRET=xK9mP2wQ7nL4vR8jT1cA6sE3bU0yF5dH

Step 4 — Install all dependencies
-----------------------------------
Run these two commands (the second one builds the frontend):

  npm install
  cd client && npm install && npm run build && cd ..

  This may take 2-3 minutes the first time.
  You should see "✓ built in X.XXs" when the build is done.

SECTION 9 — TROUBLESHOOTING
================================================================

Problem: "Cannot connect to MongoDB"
Solution: Check your MONGODB_URI in .env. Make sure:
  - Atlas: your IP is whitelisted and password is correct
  - Local: mongod service is running (mongod --dbpath /data/db)

Problem: "Port 5000 already in use"
Solution: Change PORT=5001 in .env and restart

Problem: "Module not found" errors
Solution: Re-run: npm install && cd client && npm install && cd ..

Problem: Admin panel not accessible after login
Solution: Make sure you logged in with admin@bidvault.com
  If the admin was deleted, run: node server/seed.js again

Problem: Bids not updating in real-time
Solution: Check browser console for WebSocket errors.
  Make sure the server is running. Try refreshing.

Problem: Build fails with CSS/Tailwind errors
Solution: cd client && rm -rf node_modules && npm install && npm run build
